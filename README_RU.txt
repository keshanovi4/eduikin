DEIKIN V8 — инструкция по публикации

СОСТАВ
- index.html — одностраничный сайт DEIKIN.
- assets/ — фотографии и визуальные материалы.
- netlify/functions/lead.js — серверная функция отправки заявок в Telegram.
- netlify.toml — настройки публикации Netlify.
- .env.example — пример необходимых переменных окружения.
- server.js — сервер сайта и формы для Railway, без внешних зависимостей.
- telegram-bot.js — ответы бота на /start и /chatid, автоматическая настройка webhook в Railway.
- package.json — команда npm start и версия Node.js.
- railway.json — настройки сборки, запуска и проверки доступности Railway.

ПУБЛИКАЦИЯ В RAILWAY
1) Загрузите всё содержимое папки DEIKIN_V8 в корень собственного GitHub-репозитория. package.json, server.js, telegram-bot.js, railway.json, index.html, assets/ и netlify/functions/lead.js должны попасть в репозиторий.
2) В Railway создайте New Project → Deploy from GitHub repo и выберите этот репозиторий. Если содержимое находится в подпапке DEIKIN_V8, задайте Root Directory = /DEIKIN_V8.
3) В Variables сервиса добавьте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_IDS. TELEGRAM_CHAT_IDS — chat_id получателей через запятую. Каждый получатель должен сначала открыть бота и нажать Start; либо используйте общий Telegram-чат с ботом.
4) Примените изменения и дождитесь успешного деплоя. Команда запуска npm start и проверка /health уже заданы в railway.json. PORT назначается Railway автоматически.
5) В Settings → Networking → Generate Domain получите публичный адрес сайта. При запросе порта укажите порт, на котором запустился сервер (значение PORT в Railway).
6) Откройте сайт и отправьте тестовую заявку: она должна прийти всем получателям в Telegram.
7) Для своего домена deikineducation.com добавьте Custom Domain и внесите DNS-записи, которые покажет Railway.
Без переменных Telegram страница открывается, но форма возвращает ошибку настройки и не отправляет заявки.

ЗАЯВКИ В TELEGRAM-ГРУППУ
1) Запушьте обновлённый проект и дождитесь успешного деплоя Railway. При запуске сервер автоматически регистрирует webhook Telegram через RAILWAY_PUBLIC_DOMAIN. TELEGRAM_BOT_TOKEN должен быть задан в Variables.
2) Добавьте своего бота в группу и разрешите ему отправлять сообщения.
3) Отправьте /chatid@deikin_applications_bot или /start@deikin_applications_bot (замените имя, если ваш бот называется иначе). Бот ответит ID этой группы. Поддерживается также запись /start @deikin_applications_bot с пробелом.
4) В Railway → Variables → TELEGRAM_CHAT_IDS укажите ID группы. Чтобы заявки приходили также в личку, оставьте текущий ID и добавьте ID группы через запятую: личный_ID,ID_группы. Минус в ID группы обязателен.
5) Примените переменные, дождитесь деплоя и отправьте тестовую заявку с сайта.
Команды только показывают ID чата; они не подписывают новые группы на заявки автоматически.
Webhook защищён секретом, который сервер вычисляет из токена бота. Дополнительную переменную секрета задавать не нужно. Токен не выводится в журнал.
Если публичный домен Railway недоступен автоматически, задайте TELEGRAM_WEBHOOK_URL=https://адрес-сервиса.up.railway.app/api/telegram/webhook. В журнале успешного запуска появится: Telegram commands enabled: /start and /chatid.
При временной ошибке Telegram регистрация webhook повторяется каждые 15 секунд; сайт продолжает работать.
Эта обработка команд запускается через server.js в Railway. При альтернативной публикации в Netlify работает отправка заявок, но сервер команд не запускается.

ЛОКАЛЬНЫЙ ЗАПУСК
Node.js 24; команда npm start. Откройте http://localhost:3000.
Для проверки Telegram перед запуском задайте переменные окружения из .env.example. Сервер не читает .env автоматически.
Проверка кода: npm test. Тесты используют имитацию Telegram API и не отправляют настоящих сообщений.

ПУБЛИКАЦИЯ В NETLIFY (АЛЬТЕРНАТИВА)
1) Загрузите папку DEIKIN_V8 в собственный GitHub-репозиторий.
2) Подключите репозиторий к Netlify. Publish directory = "."; functions directory = "netlify/functions". В проекте уже есть netlify.toml.
3) В Netlify → Site configuration → Environment variables добавьте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_IDS.
4) TELEGRAM_CHAT_IDS — chat_id двух получателей через запятую. Каждый получатель должен сначала открыть бота и нажать Start; либо используйте общий Telegram-чат с ботом.
5) После добавления переменных сделайте redeploy и отправьте тестовую заявку.
6) Подключите deikineducation.com в настройках домена Netlify и внесите DNS-записи, которые покажет Netlify.

БЕЗОПАСНОСТЬ
Не вставляйте токен бота в HTML, JavaScript или публичный GitHub. Храните его только в Environment variables.

ВАЖНО
Форма отправляет данные через серверный обработчик: на Railway его запускает server.js, на Netlify — платформа Netlify. Она не будет работать до настройки TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_IDS.
